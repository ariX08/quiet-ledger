# Quiet Ledger

A private, calm personal ledger for logging focused work sessions.

No streaks. No social features. No productivity theater.

Just honest time and optional short notes — stored only in your browser.

## Try it

Open `index.html` in a browser, or serve the folder:

```bash
npx serve .
```

## What it does

- Log a focused session (duration + optional note)
- See today’s total on the home page
- Review full history
- Everything stays in `localStorage`

## Design principles

- Product quality first, visual quality second, decoration last
- Semantic HTML, visible focus states, keyboard support
- Respects `prefers-reduced-motion`
- No third-party scripts, no analytics, no accounts
